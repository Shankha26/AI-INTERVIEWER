# PrepAI Pro – AI-Powered Interview Preparation and Career Readiness Platform

PrepAI Pro is a production-grade, full-stack web application designed in direct alignment with **UN Sustainable Development Goal 4 (Quality Education)**. The platform aims to bridge the gap between academic education and vocational employability by providing institutional-grade placement preparation resources like AI mock interviews, resume ATS analyzers, timed aptitude tests, and career roadmaps.

---

## Key Features

1. **Smart Student Dashboard**: Computes a dynamic, weighted **Placement Readiness Score** (Resume 25%, Aptitude 25%, Mock Interview 30%, Voice Communication 20%) alongside timelines and historical telemetry graphs.
2. **AI Resume ATS Scanner**: Processes PDF resume uploads, scores layouts 0-100, identifies missing keywords, highlights strengths/weaknesses, and maps identified skills.
3. **Conversational Mock Interview System**: Generates custom technical or HR interview questionnaires using Gemini AI, processing text answers or webcam video/audio voice recordings.
4. **Voice-Based Communication Evaluator**: Speech-to-text analysis grading candidate verbal delivery across Fluency, Confidence, Technical Accuracy, Grammar, and Relevance.
5. **Timed Aptitude Console**: Timer-driven testing center serving MCQs across Quantitative, Logical, and Verbal reasoning with instant explanations.
6. **AI Career Counselor**: Custom learning plans, cert paths, and career roadmaps generated by Gemini based on skills and interests.
7. **Personalized Study Scheduler**: Dynamic 7, 15, or 30-day study plan milestones automatically customized to student score gaps and weak subjects.
8. **Admin Control Panel**: Interface to oversee users, add/remove questions in the Question Bank, and view site-wide stats.
9. **Dual-Theme Dark/Light UI**: Responsive glassmorphism interface with automated theme toggles saved locally.

## Setup & Running Guide

### 1. Prerequisite Installations
Verify that Python 3.9+ is installed on your local computer.

Install the necessary python dependencies using `pip`:
```bash
pip install -r requirements.txt
```

### 2. Configure Environment Keys
Create a file named `.env` in the root folder of the project, or set the environment variables:
```env
# Optional: Set secret key (defaults will load if not provided)
SECRET_KEY=my_secure_app_key_123

# Optional: Set MySQL Database connection parameters.
# If these are left blank, the application automatically builds and runs on a local SQLite Database!
DB_USER=
DB_PASSWORD=
DB_HOST=localhost
DB_PORT=3306
DB_NAME=

# Required: Google Gemini API Key.
# If this is left blank, the system automatically enters simulated Mock Mode so you can safely test the entire app!
GEMINI_API_KEY=AIzaSyYourActualGeminiAPIKeyHere
```

### 3. Verify Configurations
Run the system diagnostics tool to confirm all libraries, configurations, and upload directories are initialized cleanly:
```bash
python verify.py
```

### 4. Seed Database
Run the database seeder script to initialize tables, insert pre-configured MCQ questions, and pre-register candidate/admin accounts for instant testing:
```bash
python seed.py
```

### 5. Launch Development Server
Launch the local Flask application:
```bash
python app.py
```
The application will start running at: `http://127.0.0.1:5000/`
